Sub-Issue Type: Spam — Reserved Use
Only assign the "Spam" sub-issue type when the request is specifically about:
    - A user reporting they clicked on or interacted with a spam message (not a phishing/malicious one)
    - A request to verify whether a specific email is spam
    - Noise/forwarding — a user forwarding or reporting unwanted bulk/marketing email with no security concern
    - A request to block/report a sender for spam

Do NOT use "Spam" for:
- Account compromise or unauthorized access concerns
